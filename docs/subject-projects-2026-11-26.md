# 교과 종합의견 프롬프트와 교과 프로젝트 · 2026년 11월 26일

교과 종합의견은 교과 역량 한 가지로 첫 문장을 열고, 평가별 수행과 개별 관찰은 뒤 문장에 담는다. 여러 교과가 들어 있는 HWPX 평가계획은 프로젝트명 아래 교과별 작업으로 추가한다. 작업로그와 나이스 확장은 같은 프로젝트와 교과 정보를 사용한다.

## 확정한 교과 생성 방식

- [교과 프롬프트](../prompts/subject.md)는 GPT-4o 사용 시기의 템플릿에 확정한 첫 문장 지시와 표현 차별화 지시를 반영한 버전이다. 교과 생성은 GPT-6 Luna의 추론 수준 `low`와 기본 샘플링을 사용한다.
- 첫 문장은 확인된 강점으로 바로 시작한다. ‘상’을 받은 평가 하나에서 근거를 골라 교과 역량 한 가지만 짧게 평한다. ‘상’이 없으면 입력된 가장 높은 수준의 평가를 사용한다.
- 초등 기록에서는 ‘선별·조직’ 같은 딱딱한 표현을 ‘중요한 내용을 골라 정리함’처럼 수업에서 익숙한 동사로 푼다. 교사 기록체와 교과 용어를 살리며, 구체적인 활동·성취 조건·개별 특이사항은 둘째 문장부터 연결한다.
- 같은 평가와 성취수준에서는 내용과 성취 강도를 유지하면서 어휘와 문장 연결에 작은 변화를 준다.
- 평가기준과 성취기준의 문장이나 긴 구절은 교사의 관찰 문장으로 풀어 쓴다. 교과 용어와 실제 수행 조건은 유지한다. 교과 생성은 이모지와 장식 기호를 지양하고 서버에서 이모지를 제거한 문장을 반환한다.
- 초등 6학년 국어 23명 검증에서 서로 다른 문단 23개와 첫 문장 19종이 나왔다. 실제 사용 전에는 평가나 교사 메모로 확인되는 수행인지 살핀다. ‘글을 나눔’에서 ‘의견을 주고받음’으로 확대하거나, 참여 수준의 쓰기에 별도 시간이나 갈래를 덧붙이는 경우가 있었다.

## HWPX 적용과 프로젝트 저장

- 평가계획 분석으로 교과명, 영역, 성취기준, 평가기준, 핵심역량을 가져온다. 학생별 상·중·하는 각 교과 작업에서 입력한다.
- 저장본 편집 중에는 ‘교과 작업에 추가’와 ‘현재 저장본에 교과 하나 적용’을 선택할 수 있다. 여러 과목이 분석되면 첫 번째 선택을 기본값으로 제시한다. ‘교과 작업에 추가’로 만든 교과는 같은 프로젝트명 아래 표시된다.
- ‘프로젝트 저장’은 그 프로젝트의 교과별 임시 작업을 하나의 프로젝트 저장본으로 묶는다. 작업로그에서 프로젝트를 펼쳐 교과별 보기, 수정, 내보내기, 보관을 이용할 수 있다.
- 나이스 확장에서 프로젝트 작업로그를 불러오면 그 안의 교과 탭이 표시된다. 선택한 탭의 학생별 결과를 불러오고 최신 버전을 대조한 뒤 해당 교과 결과를 붙여넣는다.

## DB 관계와 이전 기록

`subject_projects`는 프로젝트명과 소유자를 가진다. 교과별 임시 작업인 `work_logs`는 프로젝트에 연결되며, 저장 시 별도의 프로젝트 저장본을 만들어 당시 교과별 기록을 복사한다. `subject_project_saved_logs`는 교과 저장본과 프로젝트 저장본을 연결한다. 연결과 조회에는 소유자 제한이 적용된다.

업데이트 전 이관된 교과는 이관 식별자가 있는 저장본을 기준으로 프로젝트에 연결한다. 연결을 추가할 때 각 교과 기록의 작성 결과, 평가 기준, 성취수준, 개별 메모와 저장 버전은 기존 값을 사용한다. 기존 단독 저장본도 교과별로 계속 열 수 있다.

## 11월 26일 검증과 데이터 정리

- 국어·수학 평가계획 검증 파일을 저장본 편집 화면에서 선택해 두 교과를 하나의 임시 프로젝트에 적용했다. 브라우저 검증에는 합성 분석 응답을 사용했다. 기존 저장본의 평가·작성 결과·메모, 단일 교과 적용 선택지, 프로젝트 저장과 교과별 열람을 확인했다.
- DB 트랜잭션에서 가져오기와 저장 재시도, 교과별 학생 데이터 보존, 다른 계정 접근 제한을 검증한 뒤 검증 데이터는 롤백했다.
- 운영 계정의 이전 교과 저장본 10개를 ‘업데이트 전 교과 기록’에 연결했다. 저장본 10개를 전체 필드로 다시 읽어 연결 전과 일치함을 확인했다. 최신 국어의 ‘우리 말’ 네 건은 ‘우리말’로 고쳤다.
- 성취수준 입력이 없는 교과 작업은 평가를 입력한 뒤 생성한다. 평가계획의 성취수준 설명은 학생별로 받은 성취수준과 구분한다.

같은 날 운영 DB에서 8월 1일 0시(KST) 전 교과 작업로그 저장본 130건을 정리했다. 프로젝트 연결 10건도 함께 사라졌으며, 작업 탭과 이후 저장본의 건수를 대조했다. 확장 v0.1.13은 프로젝트 불러오기 후 교과 탭이 표시되고, 선택한 교과만 나이스 패널에 전달되는 흐름을 모의 데이터로 검증했다.
