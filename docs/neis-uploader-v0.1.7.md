# 나이스 확장 프로그램 0.1.7

2026-11-05. 작업로그 개편 이후 웹스토어의 0.1.6 패키지를 교체하기 위한 릴리스입니다.

## 변경

- 행특·창체·교과 모두 저장된 작업로그를 제목, 작성 인원, 저장 시각으로 골라 불러옵니다. 목록은 30개씩 조회합니다.
- 저장본 / 보관본을 나누어 선택합니다. 보관본은 읽기만 하며, 확장은 원본 작업로그를 변경하지 않습니다.
- 웹앱에서 수정 후 저장한 결과와 윤문을 적용해 저장한 결과를 그대로 가져옵니다. 패널 전달 직전에 revision을 확인하여 변경된 결과는 새 미리보기를 확인하도록 안내합니다.
- 영역·작업로그·계정 변경, 빈 목록, 요청 실패, 로그아웃 시 이전 웹 결과를 재사용하지 않습니다. 늦게 도착한 이전 요청도 무시합니다.
- 이전 버전의 가져온 데이터는 업그레이드 시 지웁니다. 새 웹 결과는 팝업 메모리에만 유지합니다. CSV는 새 전용 키에 저장하고 초기화/로그아웃으로 삭제합니다.
- 새 작업로그 CSV의 `작성 결과` 열을 명시적으로 인식합니다. CSV 모드에서도 나이스 입력 영역을 선택할 수 있습니다.
- 기존 나이스 페이지 내 업로더와 입력칸 선택자는 바이트 단위로 동일합니다. 권한과 호스트 권한도 기존 0.1.6과 동일합니다.

## 검증

- `node --experimental-strip-types --test tests/*.test.mjs`: 32개 통과(기존 21개 + 확장 11개).
- 브라우저 팝업 + 모의 Chrome/API: 30명 저장본 선택, 23명 보관본, 갱신된 revision 재확인, 영역 변경, 빈 응답, CSV, 로그아웃 및 실제 전달 payload 확인. 가로 넘침 없음.
- 별도 Chrome for Testing 프로필에 배포용 폴더를 실제 압축해제 확장으로 설치: manifest 0.1.7 인식, 운영 로그인→브리지 세션 전달, 실제 운영 API로 행특·교과·창체 조회 및 가져오기, 보관본 목록 조회 통과. 웹 학생 결과가 chrome.storage에 저장되지 않는 것 확인. 운영 작업로그는 읽기만 했습니다.
- 패키징: 실행 파일 10개 allowlist, ZIP CRC 검증, 모든 ZIP 바이트와 소스 일치, `manifest.json` 최상위 및 버전 확인, SHA-256 기록.
- 실제 나이스 계정에서 입력/저장은 수행하지 않았습니다. 변경하지 않은 나이스 업로더의 현장 동작은 기존 버전과 동일한 범위입니다.

## 업로드

생성 명령: `python3 scripts/package-extension.py`

- ZIP: `dist/releases/neis-uploader-v0.1.7/for-teacher-ai-neis-uploader-v0.1.7.zip`
- 로컬 설치 폴더: `dist/for-teacher-ai-neis-uploader-v0.1.7`
- 체크섬: ZIP과 같은 폴더의 `SHA256SUMS`
- 기존 웹스토어 항목: `kccpnhgkaombpfajdjgonenibmglpcmp`

Chrome 개발자 대시보드에서 **기존 항목 → 패키지 → 새 패키지 업로드**로 ZIP을 올린 후 **검토를 위해 제출**합니다. 새 항목을 생성하지 않습니다. 기존 등록 설명과 데이터 처리·권한 범위에 변경이 필요한지 확인하고, 아래 변경 설명을 사용할 수 있습니다.

> 작업로그에서 저장본과 보관본을 직접 선택해 나이스로 가져올 수 있습니다. 제목·저장 시각·작성 인원을 표시하며, 최신 저장 결과를 확인하고 이전 데이터가 남지 않도록 개선했습니다. 새 작업로그 CSV 형식을 지원합니다.

이 문서 작성 시 공개 웹스토어 버전은 0.1.6이었습니다. 이 저장소의 패키지 생성·반영은 웹스토어 업로드/심사 제출과 별개입니다. 이 작업에서는 웹스토어에 업로드하거나 심사 제출하지 않았습니다.

공식 절차: [Chrome Web Store 업데이트 안내](https://developer.chrome.com/docs/webstore/update).
