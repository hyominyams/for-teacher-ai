# ForTeacher AI NEIS Uploader 0.1.7

ForTeacher AI의 저장된 작업로그 또는 CSV를 선택해 나이스 입력 패널로 전달하는 Chrome Manifest V3 확장 프로그램입니다.

## 작업로그 가져오기

1. 웹앱에서 결과를 확인하고 **작업로그에 저장**을 누릅니다. 입력 필드를 비우거나 새 작업을 시작해도 이 저장본은 유지됩니다.
2. 확장 팝업에서 **웹앱 계정 연결**을 누르고 브리지 화면에서 로그인합니다. 연결이 만료되면 **계정 다시 연결**로 갱신합니다.
3. 나이스 입력 영역(행특 / 학기말 종합의견 / 창체)을 선택합니다.
4. **저장본** 또는 **보관본 · 읽기 전용**을 선택합니다. 제목·저장 시각·작성 인원을 확인하고 가져올 작업로그를 고릅니다. 목록은 30개씩 표시하며 이전/다음으로 이동합니다.
5. **선택한 작업로그 불러오기**를 누르고 학생 번호와 내용을 확인합니다. 결과가 비어 있는 학생은 제외됩니다.
6. 나이스 입력 화면에서 확장을 열어 **나이스 화면에 패널 띄우기**를 누릅니다. 나이스 패널에서 첫 입력칸과 시작 번호를 확인한 뒤 **시작**을 누릅니다.

보관본도 읽어서 나이스로 가져올 수 있지만 원본을 수정하지 않습니다. 확장은 작업로그 API에 GET 요청만 보냅니다. 새 버전은 자동 저장 중인 초안 대신 명시적으로 저장한 작업로그를 사용합니다.

웹앱에서 수정 후 저장했다면 **목록 새로고침 → 작업로그 불러오기**로 갱신합니다. 패널을 열기 직전에도 버전을 확인하며, 내용이 바뀌었으면 최신 미리보기를 표시하고 다시 확인하도록 안내합니다.

## CSV

CSV 선택 후 입력 영역을 지정하고 파일 또는 클립보드에서 불러옵니다. `번호`, `이름`/`성명`, `작성 결과`/`AI 생성 결과` 등의 헤더를 지원합니다. 쉼표·줄바꿈·따옴표가 포함된 CSV도 읽습니다.

## 데이터 보관

웹앱 학생 결과는 팝업 메모리에만 유지하며, 팝업을 다시 열 때 선택한 작업로그를 다시 불러옵니다. 업데이트 직후 이전 버전에서 불러온 데이터는 지우므로 작업로그나 CSV를 다시 불러오세요. 직접 불러온 CSV는 이 브라우저에 저장되며 **초기화** 또는 **로그아웃** 시 삭제됩니다. 계정 변경, 영역/저장본 변경, 목록 갱신 실패 때 이전 웹 결과를 계속 사용하지 않습니다.

## 개발 설치와 패키징

```sh
python3 scripts/package-extension.py
node --experimental-strip-types --test tests/*.test.mjs
```

- `chrome://extensions`에서 개발자 모드를 켜고 `dist/for-teacher-ai-neis-uploader-v0.1.7`을 **압축해제된 확장 프로그램을 로드**로 선택합니다.
- 웹스토어 업로드: `dist/releases/neis-uploader-v0.1.7/for-teacher-ai-neis-uploader-v0.1.7.zip`.
- `manifest.json`이 ZIP 최상위에 위치하며, 실행 파일 10개만 포함합니다. API 키·로그인 토큰·테스트·개인 데이터는 패키징하지 않습니다.
- 기존 권한과 호스트 권한은 0.1.6과 동일합니다. `config.js`의 운영 주소는 `https://for-teacher-ai.vercel.app`입니다.

## 나이스 호환성

0.1.6의 입력 선택자와 페이지 내 업로더는 유지합니다. 행특/창체는 `data-cellindex='3'`, 학기말 종합의견은 `data-cellindex='4'`를 우선 탐색합니다. 전체 프레임에서 나이스 편집칸을 찾고 오버레이 패널을 띄웁니다. 나이스 자체의 로그인·입력 화면 구조가 변경되면 별도 실환경 점검이 필요합니다.
