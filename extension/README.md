# ForTeacher AI NEIS Uploader

Chrome Extension Manifest V3 기반 나이스 입력 자동화 MVP입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 우측 상단의 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 저장소의 `extension` 폴더를 선택합니다.

## 웹앱 계정 연결

1. ForTeacher AI 웹앱을 실행합니다.
2. 확장 팝업에서 `웹앱 계정 연결`을 누릅니다.
3. 브리지 화면에서 Google 계정으로 로그인합니다.
4. 확장 팝업을 다시 열고 나이스 입력 영역을 선택합니다.
5. 저장본/보관본과 작업로그를 고른 뒤 `선택한 작업로그 불러오기`를 누릅니다. 교과는 작업로그 제목으로 구분합니다.

브리지 기본 주소는 `config.js`의 `appOrigin` 값을 사용합니다.

## 사용

1. 웹앱 저장 데이터 또는 내 CSV·XLSX 파일을 불러옵니다.
2. 나이스 입력 화면을 엽니다.
3. 첫 학생 입력칸을 클릭합니다.
4. 확장 팝업에서 `나이스 화면에 패널 띄우기`를 누릅니다. 패널의 `붙여넣기 방식`에서 `기존 내용 뒤에 이어쓰기`(기본) 또는 `기존 내용 덮어쓰기`를 선택한 뒤 `시작`을 누릅니다.
5. 입력 결과를 확인하고 나이스에서 직접 저장합니다.

이어쓰기는 각 학생의 기존 문장 끝에 공백 한 칸을 두고 같은 줄에 새 문장을 붙입니다. 예: `기존 문장. 새 문장.` 빈 칸에는 새 문장만 들어갑니다. 파일과 웹앱 작업로그 모두에서 사용할 수 있습니다. 기존 내용을 읽을 수 없거나 입력칸에 지정된 글자 수 제한을 넘으면 해당 칸은 변경하지 않고 중단합니다. 이어쓰기를 같은 학생에게 다시 실행하면 새 문장이 한 번 더 붙으므로, 중단 후 재시작할 때는 시작 번호를 확인하세요.

## 내 CSV·XLSX 파일 사용 (계정 연결 불필요)

1. 데이터 방식을 `내 파일 (CSV·XLSX)`로 바꿉니다.
2. `행특` / `학기말 종합의견` / `창체(자율)` 영역을 선택하고 해당 영역의 `예시 CSV 다운로드`를 누릅니다.
3. 예시 학생을 실제 학생으로 교체합니다. 열은 `번호,이름,행특`, `번호,이름,학기말종합`, `번호,이름,창체`이며, 영역별 마지막 열에 완성된 문장을 작성합니다. 이름은 비워도 됩니다. 번호는 나이스 학생 번호와 같아야 합니다.
4. CSV 또는 XLSX로 저장한 뒤 업로드합니다. XLSX는 **첫 번째 시트만** 읽습니다. 교과·학급별 파일을 따로 준비하세요.
5. 불러온 목록의 영역·번호·내용을 확인하고 해당 영역의 나이스 입력 화면에서 패널을 엽니다.

- 열 순서는 바꿔도 됩니다. 공통 `내용` 열과 기존 웹앱 CSV의 `AI생성결과`, 작업로그 CSV의 `작성 결과` 열도 지원합니다. 한 파일에는 하나의 영역과 하나의 교과·학급만 넣습니다.
- 번호는 양의 정수이며 중복되면 안 됩니다. 빈 행은 무시하지만 번호가 있는 행의 내용이 비어 있으면 행 번호와 함께 오류를 안내합니다. 입력하지 않을 학생은 행 전체를 삭제하세요.
- 쉼표·따옴표·줄바꿈이 있는 내용과 UTF-8 / Excel 한국어 CSV를 지원합니다. 최대 5MB, 2,000명입니다.
- 오류가 있으면 파일 전체를 적용하지 않고 기존 목록을 유지합니다. 영역별 파일 목록은 기기에 보관하며 팝업을 다시 열어도 복원됩니다. 웹앱에서 조회한 학생 결과는 팝업 메모리에서만 처리하고 작업로그 원본을 수정하지 않습니다. `초기화` 또는 `로그아웃`은 불러온 학생 목록을 지웁니다.
- 파일 데이터는 나이스 행의 **번호 열**을 대조해 입력합니다. 예를 들어 1번·3번만 있는 파일은 2번을 건너뜁니다. 번호나 입력칸을 확인할 수 없으면 중단하고 안내합니다. 실제 나이스에서 저장하기 전 결과를 확인하세요.
- 파일 파싱은 확장 프로그램 안에서 수행하며 파일을 서버에 업로드하지 않습니다. XLSX 파서는 확장에 포함되어 있어 외부 스크립트를 요청하지 않습니다.

### XLSX 라이브러리

SheetJS CE 0.20.3의 공식 브라우저 배포본을 `vendor/xlsx.full.min.js`에 포함합니다. 출처: https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js

공식 설치 문서: https://docs.sheetjs.com/docs/getting-started/installation/standalone/ · 라이선스: `vendor/SHEETJS-LICENSE.txt` (Apache 2.0). 웹앱의 npm 의존성은 변경하지 않습니다.

가져오기·기존 작업로그 회귀 테스트: `node --test tests/extension-import.test.mjs tests/extension-popup.test.mjs` (저장소 루트에서 실행).

## 나이스 화면 확인 시 조정할 부분

나이스 입력칸이 일반 `textarea`가 아니거나 특수 그리드 컴포넌트라면 확장 팝업의 `입력칸 선택자` 또는 `popup.js`의 `runUploaderInPage` 입력 로직을 화면 구조에 맞게 조정해야 합니다.

현재 MVP는 모든 프레임에서 실행되므로 나이스 입력칸이 iframe 안에 있어도, 사용자가 첫 입력칸에 커서를 둔 상태라면 `현재 칸부터 쭉 입력`으로 시작할 수 있습니다.

첨부 DOM 기준 행특 입력칸 기본 선택자는 다음입니다. 파일 모드는 영역 이름이 있는 입력칸만 허용하고 범용 입력칸으로 대체하지 않습니다.

```text
.cl-grid-cell[data-cellindex='3'] .cl-textarea:not(.cl-disabled)
```

창의적 체험활동의 자율/자치활동 화면은 확장 팝업에서 `창체(자율)`을 선택하면 다음 선택자를 사용합니다.

```text
.cl-grid-cell[data-cellindex='3'][aria-label*='특기사항']:not([aria-label*='행동특성']):not([aria-label*='종합의견']) .cl-textarea:not(.cl-disabled)
```

학기말 종합의견(교과) 화면은 `학기말 종합의견` 편집창이 4번 열에 있어 확장 팝업에서 `학기말 종합의견`을 선택하면 다음 선택자를 사용합니다.

```text
.cl-grid-cell[data-cellindex='4'][aria-label*='학기말 종합의견'] .cl-textarea:not(.cl-disabled), .cl-grid-cell[data-cellindex='4'] .cl-textarea:not(.cl-disabled)
```

v0.1.8 변경·검증 범위는 [`docs/neis-file-import.md`](../docs/neis-file-import.md)에 기록합니다.
